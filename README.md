# VSP Student Assistant

Телеграм-бот для организации учебного процесса.  
Позволяет структурированно хранить учебные материалы, заметки и файлы по предметам и датам.

## Функциональность

- Добавление заметок для каждого предмета
- Разделение данных по семестрам
- Структура:
  - Семестр
  - Предмет
  - Лекции
  - Семинары
  - Домашние задания
  - Заметки
- Привязка записей к конкретной дате
- Возможность прикрепления:
  - до 10 файлов
  - до 10 изображений
- Раздел для общих заметок на всё время обучения
- Удобное inline-меню
- Выбор даты через пагинацию
- Система администрирования

## Технологии

- Python
- Telegram Bot API
- SQLite / Database
- Inline Keyboard

## Назначение проекта

Проект создан для автоматизации и удобного хранения учебных материалов в Telegram.
